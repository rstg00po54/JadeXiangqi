# JadeXiangqi 独立 PNG 素材包

面向 Android 1260×2800 竖屏，原创木质国风统一视觉。PNG 为真实单独文件，不是从一张大拼图里硬裁出的资源。

- pieces/red、pieces/black：每枚棋子 512×512 透明 PNG。红帅仕相马车炮兵；黑将士象馬車砲卒。实际每方数量由游戏逻辑复制。
- board：1120×1260 标准 9×10 中国象棋棋盘。包括楚河汉界、九宫线和标记。
- buttons：5 套 768×176 可复用、无文字的透明按钮底图。按钮文字请在 Android UI 层绘制。
- icons：13 个 256×256 透明独立图标。
- panels：信息面板、底部导航背景。
- backgrounds：lobby、game 两张 1260×2800 背景 JPG。
- preview：布局示意图，仅作参考，不作为程序素材使用。
- app_icon_512.png：应用图标。

棋盘精确坐标（原图 1120×1260）：左上交叉点 x=100、y=97；相邻交叉点间距 x=115、y=116；沿两个方向分别 9 列和 10 行。棋子应以交叉点为中心绘制。

本素材不是 JJ 象棋官方原版资源；如果需要对应截图 1:1 还原，需要提供明确的参考图。
