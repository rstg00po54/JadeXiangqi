# 玉弈象棋 · vivo X300 Pro 竹窗茶室 UI（1260×2800）

以你提供的阳光茶室象棋首页为设计参考，独立绘制的另一套**暖木色、竹林圆窗、石板棋桌、金边控件**的素材，没有复用 JJ 游戏原文件。

**手机型号**：vivo X300 Pro，原生竖屏分辨率 **1260×2800**（9:20）。

**全屏主页背景**：`backgrounds/tea_room_lobby_background_1260x2800.png`，精确 1260×2800；**完整主页预览**：`preview/home_mockup_1260x2800.png`，同分辨率。旧的 1080×1920 主页背景已从此修订包移除。

棋盘、棋子、按钮不是全屏背景，仍使用各自的尺寸，并由 Android 界面按容器缩放，不能把它们直接拉伸成 1260×2800。

## 目录
- `backgrounds/`：竹窗茶室的竖屏首页背景、茶室 Banner，以及竹林装饰场景。
- `boards/`：两款 **准确 9 路 × 10 横线**的象棋棋盘（中间楚河汉界断线、双方九宫斜线）。
- `pieces/`：红黑各 7 种棋子、空棋子，透明 256×256 PNG，中文棋子字由字体精确绘制。
- `buttons/`：透明背景的木金浮雕模式按钮，象棋／揭棋／开始对局／残局闯关／棋谱复盘／AI对战，含无字通用按钮。
- `icons/`：10 个 256×256 金边翡翠圆形功能图标：学棋、商城、荣誉、我的、提示、复盘、悔棋、设置、菜单、表情。
- `decorations/`：头像框、计时器圆环、金币、选中光圈、合法落点标记。
- `concept/`：AI 生成的设计总览大图（仅供设计参考，不能直接当作拆分后的可点击 UI）。
- `preview/`：资源概览图。

## Android 推荐用法
资源可拷贝到 `app/src/main/assets/ui_tearoom/`，或者根据用途放进 `res/drawable-nodpi/`。
背景、按钮、头像框可由 `ImageView` 渲染；**对局状态、倒计时文字和棋子动画应由代码控制**。

注意：场景 Banner 来自 AI 原创效果图的局部裁剪，适合作为装饰艺术，不适合高精度矢量缩放；棋盘格和文字是重新程序绘制的可靠资源，不直接依赖 AI 绘制的棋盘位置。
